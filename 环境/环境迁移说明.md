# nlpbase 环境迁移说明

> 目标：在第二台电脑上重建一个和现在**一模一样**的 `nlpbase` 环境。
> 本目录四个文件配套使用，跟着 README 走一遍大约 15 分钟（不含模型下载）。

---

## 一、为什么不是直接打包拷贝

| 方式 | 结果 |
|---|---|
| 直接复制 `envs\nlpbase` 目录 | ❌ 5.4 GB，且 python.exe 里写死了原路径，换盘就废 |
| `conda-pack` 打包 | ⚠️ 能小一点，但 C 扩展和 CUDA 库仍可能指向旧路径 |
| **重装（本方案）** | ✅ 15 分钟，干净，出问题好排查 |

**核心原则：只迁移"清单"，不迁移"文件"。**

---

## 二、本机环境快照

| 项 | 值 |
|---|---|
| Python | 3.10.21（conda-forge） |
| PyTorch | **2.14.0+cu130**（CUDA 13.0 构建） |
| 支持的算力 | sm_75 / 80 / 86 / 90 / 100 / **120** |
| 显存相关 | RTX 5060 Ti，compute capability **(12, 0)** |
| 包总数 | 140 个 pip 包 |
| 环境体积 | 5.41 GB |

> **关键**：`cu130` 这个 wheel 从 Turing（7.5）一路编译到 Blackwell（12.0），
> 所以新电脑只要是 NVIDIA 卡（GTX 16 系之后）都能直接用。

## 三、前置：装 Miniconda

新电脑上装 **Miniconda**（不用 Anaconda，省 3 GB）：
<https://docs.conda.io/en/latest/miniconda.html>

装完在开始菜单里打开 **Anaconda Prompt**（或 PowerShell 里先跑一次 `conda init powershell`）。

## 四、方式 A：一键脚本（推荐）

把本目录整个拷到新电脑（或 `git clone` 仓库），然后：

```powershell
cd 路径\环境
.\setup.ps1 -DryRun     # 先干跑一次，只打印将要执行的命令，不安装
.\setup.ps1            # 确认无误后正式安装
```

脚本会依次：检查 conda → 探测显卡 → 建环境 → 装 torch → 装依赖 → 跑验证。

**如果报"未对文件进行数字签名"**（Windows 默认执行策略），用这一行绕过：

```powershell
powershell -ExecutionPolicy Bypass -File .\setup.ps1
```

**三种变体：**

```powershell
.\setup.ps1                # 默认：CUDA 13.0
.\setup.ps1 -Index cu128   # 新电脑驱动较老，降到 CUDA 12.8
.\setup.ps1 -Cpu           # 没有 NVIDIA 显卡，装 CPU 版
```

> 如果 PowerShell 提示"禁止运行脚本"：
> ```powershell
> Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
> ```

## 六、方式 C：像素级复现（怀疑版本不一致时用）

`requirements-lock.txt` 是本机 **140 个包的全量冻结**：

```powershell
conda activate nlpbase
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu130

```

> 注意：lock 文件里带着 `torch==2.14.0+cu130`，从 PyPI 装会找不到这个版本号
> —— 所以要先按第六步用 PyTorch 官方源装 torch，再装 lock 时它会自动跳过已满足的。

## 八、踩过的坑（新电脑上大概率还会遇到）

**① 显卡驱动太老，torch 装完用不了**
`cu130` 需要 NVIDIA 驱动 **580 以上**。旧驱动请改用 `-Index cu128` 或 `cu126`。
判断方法：`nvidia-smi` 右上角显示的 CUDA Version 要 ≥ torch 的构建版本。

**② 报 `no kernel image is available for execution`**
这是 **sm_120（Blackwell）** 没有被编译进 wheel。装错版本了，重装 cu128 及以上的 wheel。
验证：
```python
import torch
print("sm_120" in torch.cuda.get_arch_list())   # 必须是 True
```

**③ 路径里有中文**
`SummaryWriter` 走 TensorFlow 的 gfile，中文相对路径会报
`FailedPreconditionError: ... is not a directory`。
**日志目录用全英文绝对路径。**

**④ 训练 `loss=nan`，不报错**
先查 dtype。`config.json` 写 bf16，但先加载到 CPU 会被降级成 fp16；
fp16 下 AdamW 的 `eps=1e-8` 下溢成 0，第一步就产生 nan。
加载时显式指定：`from_pretrained(path, dtype=torch.bfloat16)`。

**⑤ TensorBoard 命令拼错**
是 `--logdir`，不是 `--logdis`。

**⑥ 环境能装但 tensorflow 冲突**
`tensorflow==2.19.0` 只在你需要词向量投影可视化时才装，**默认不装**（省 1.5 GB）。
TensorBoard 本身不需要 TF 也能记录标量。

## 十、第二台机器：RTX 3060 Laptop（6 GB）专项说明

### 10.1 能直接迁，但要用同一个 CUDA 版本

| 项 | 本机 5060 Ti | 第二台 3060 Laptop |
| --- | --- | --- |
| 架构 | Blackwell | **Ampere** |
| 算力 | sm_120 | **sm_86** |
| 显存 | 16 GB | **6 GB** |
| 驱动 | 616.64 | 610.88 |

`cu130` 这个 wheel 的编译列表是 `sm_75 / 80 / 86 / 90 / 100 / 120`——**sm_86 在里面**，所以第二台机器照样用 `.\setup.ps1`，不用改参数。

> 驱动版本换算：Windows 的 `32.0.16.1088` 对应 NVIDIA 的 **610.88**（取后 5 位 `61088`）。
> cu130 要求 ≥ 580，610.88 满足。

### 10.2 显存是真正的瓶颈

你现在的配置（batch 2 + seq 1024 + AdamW）实测峰值 **10.27 GB**，6 GB 卡上**必然 OOM**。

6 GB 的固定开销先算一遍（0.6B 模型，bf16）：

```
权重          1.19 GB
梯度          1.19 GB
AdamW m / v   2.38 GB
---------------------------
合计          4.76 GB   ← 模型还没开始算，只剩 1.2 GB
```

剩下 1.2 GB 要装激活值 + logits（`1 × 512 × 151936 × 2B ≈ 155 MB`），非常紧。

### 10.3 第二台机器上要改的四个参数

在 `SFT_demo.py` 里（或复制一份 `SFT_demo_6g.py`）：

```python
max_length   = 512     # 1024 → 512，激活值直接减半
batch_size   = 1       # 2 → 1
grad_accum   = 8       # 新增：累积 8 步，等效 batch 仍为 8
```

再在模型加载后加一行，用时间换显存：

```python
model.gradient_checkpointing_enable()   # 省约 40% 激活值，速度慢约 30%
```

梯度累积的写法（**先除再反传**，否则 8 步累积等于把学习率放大 8 倍）：

```python
loss = loss / grad_accum
loss.backward()
if (step + 1) % grad_accum == 0:
    optimizer.step()
    optimizer.zero_grad()
```

### 10.4 还不行的话，按这个顺序退

| 顺序 | 手段 | 代价 |
| --- | --- | --- |
| 1 | `max_length` 降到 384 | 长对话被截断更多 |
| 2 | 8-bit 优化器（`bitsandbytes`） | Adam 状态从 2.38 GB 降到 0.6 GB |
| 3 | 只训部分层（冻结底层） | 效果下降 |
| 4 | **LoRA**（day04 内容） | 可训参数降到 1% 以下，6 GB 很轻松 |

### 10.5 速度预期

3060 Laptop 的算力约为 5060 Ti 的 1/3～1/2（还受笔记本功耗墙影响）。
本机 batch 2 / seq 1024 是 0.68 s/步，第二台改 batch 1 / seq 512 后，
**大约 0.8～1.5 s/步**，100 步要 1.5～2.5 分钟。调流程够用，正式训练建议还是回 16 GB 那台。
